上飞轮沿 y 轴偏置 Δy，会怎样影响转向？

先纠正方向：这里讨论的是侧向偏置 Δy，不是前后偏置 Δx。侧向偏置直接带来横滚重力矩；它也会使俯仰和偏航的惯量耦合。是否能留下可控的净转角，取决于运动循环和轮地接触。

本文是对假设改装的建模分析，不是原版 Wheelbot 或 Mini Wheelbot 已验证的结构。下面的交互部分使用固定接地点的简化模型；行驶中的预测须加入滚动约束。若要看 Δx 前偏置时横滚怎样带出偏航，见逐帧动量图与摩托车对照。

1. 坐标系与两只轮子的方向

x：机器人前进方向；y：侧向，规定向左为正；z：竖直向上。下轮在 xz 平面内，轮轴与角动量沿 y；上飞轮在 yz 平面内，轮轴与角动量沿 x。你给出的方向定义是对的。

取下轮接地点 O 为原点。上飞轮总成质心原来是 (0, 0, h)，现在改为 r = (0, d, h)，其中 d = Δy。d 是固定安装偏置；上飞轮轴仍沿 x，没有新增转向电机。质量 m 指随偏置一起移动的飞轮、电机和支架总质量。

若只移动转子、不移动电机和支架，应按各零件真实位置分别计算质心和惯量，不能把整个总成质量都放在 d 处。

2. 第一个直接后果：它想让机器人侧倾

重力 Fg = (0, 0, −mg) 对接地点的力矩为：

r × Fg = (−mgd, 0, 0)

这是绕 x 的横滚力矩，不是绕 z 的偏航力矩。对照来看，前后偏置 Δx 的重力矩才是俯仰方向。固定侧偏置会让横滚控制器持续补偿，或者让机器人在一个非零横滚角附近平衡。

设其余部件的质量高度和为 S = Σmihi，则静态横滚平衡角满足下式；没有控制器时，这只是质心位于接地点正上方的几何条件。

tan φ0 = md / (S + mh)；小角度时 φ0 ≈ md / (S + mh)
偏置方向重力首先造成新增的偏航惯性耦合
Δx：前后偏置俯仰力矩Ixz = −mΔx·h，横滚 ↔ 偏航
Δy：侧向偏置（本页）横滚力矩Iyz = −mΔy·h，俯仰 ↔ 偏航

图中示例取 m = 0.13 kg、h = 0.09 m、S = 0.034 kg·m。它们是演示参数，不是 Mini 的识别值。

3. 第二个后果：侧偏置把俯仰与偏航连起来

只为分离这一项，先令横滚 φ = 0、上轮相对自转速度为 0，并近似固定接地点。令 θ 为绕 y 的俯仰角，ψ 为绕 z 的偏航角。质量 m 的惯量张量新增 Iyz = −mdh；它对应俯仰—偏航交叉项。

Tm = ½m[h²θ̇² − 2dh cosθ · θ̇ψ̇ + (d² + h²sin²θ)ψ̇²]

这个式子可以直接复核：机身角速度在机身坐标中是 ω = (−ψ̇sinθ, θ̇, ψ̇cosθ)，代入 Tm = ½m|ω × (0,d,h)|²。把其余部件的等效偏航惯量记为 C；若没有地面偏航力矩，ψ 是循环坐标，偏航广义动量守恒：

pψ = [C + m(d² + h²sin²θ)]ψ̇ − mdh cosθ · θ̇ = 常数

若起初 pψ = 0，小角度下便有：

ψ̇ ≈ k θ̇，　ψ̈ ≈ k θ̈，　k = mdh/(C + md²)

这说明侧偏置确实会让下轮驱动所造成的俯仰运动伴随偏航。但在这个单自由度理想模型中，θ 回到起始角时，ψ 也回到起始角。它给的是瞬态耦合，还不能直接当作“固定 Δy 就有可控方向盘”。

4. 侧倾还会改变下轮的角动量方向

下轮轮轴原本沿机身 y。若侧向重心偏移使机器人在 φ0 ≠ 0 处平衡，下轮轴的竖直投影约为 sinφ0。于是下轮轴向角动量 HW = JWΩW 会带有竖直分量 HW,z ≈ JWΩWsinφ0。上轮轴沿 x，单纯侧倾不会使它的轴出现竖直投影。

这意味着下轮加减速时，还可能与偏航交换角动量。但下轮与地面接触，ΩW 同时决定前进滚动；接触点在移动，也可能有摩擦力矩。不能仅用角动量投影就断言一个可用的转向增益或转弯半径。

局部、示意性的偏航动量：
pψ ≈ Jψψ̇ − mdh θ̇ − JRΩRsinθ + JWΩWsinφ

四项分别表示：机身偏航、侧偏置造成的俯仰—偏航惯性耦合、上飞轮原有的陀螺耦合、侧倾时下轮轴向角动量的竖直投影。真实模型还含惯量随姿态变化、滚动接触和摩擦项。这是小角度机理式，不是完整轮地动力学方程。

5. 固定 Δy 可以作为转向设计参数吗？

问题结论
侧偏置会不会产生力矩？会产生横滚重力矩 −mgd；不会由重力直接产生偏航力矩。
能否让原来分离的运动耦合？能。它新增 Iyz = −mdh，使俯仰和偏航在惯性上耦合。
固定 Δy、只做俯仰往返，能否留下净转角？在本页无偏航外力矩、固定接地点、横滚锁定的模型里不能；回正会抵消。
行驶中能否利用它控制转向？有可能改变转向响应，尤其在非零侧倾下；必须连同接地滚动、飞轮速度和闭环平衡控制一起验证。
主要工程代价？横滚平衡点偏移、持续补偿或侧倾、驱动与转向更强耦合、对称自扶正特性可能改变。

要预测真实转弯，模型还缺什么？

取广义坐标 q = (xO, yO, ψ, θ, φ, qW, qR)，上飞轮总成位置写成：

rF(q,d) = (xO, yO, 0) + Rz(ψ)Ry(θ)Rx(φ)(0,d,h)

用 rF 的雅可比和各刚体角速度构造质量矩阵 M(q;d)，用势能求重力项，再加入下轮的无侧滑、纯滚动约束及接触力：

M(q;d)q̈ + C(q,q̇;d)q̇ + g(q;d) = Bτ + A(q)Tλ，　A(q)q̇ = 0

应对比 d = 0、正 d、负 d 三种情况，在相同目标速度与朝向命令下比较偏航跟踪、侧倾角、两台电机力矩及打滑。上式是建模路线；真实接地点随轮子几何变化，不能简单把动画的固定 O 假设直接用于实车。

6. 如果从直立开始，只改变上飞轮转速呢？

这里必须区分“始终严格直立”和“只在初始时刻直立，随后允许机身运动”。飞轮电机绕 x 轴输出力偶；把电机安装位置沿 x 或 y 平移，力偶仍绕 x，均不会直接变成绕 z 的力偶。

直立附近：Jψψ̈ ≈ mhΔx·φ̈ + mhΔy·θ̈ + JR(Ω̇Rθ + ΩRθ̇) + 其他接触项
条件只改变上飞轮速度时的理想模型结论
φ = θ = 0 被约束在整个过程中保持Δx、Δy 都不能产生偏航：上轮轴始终水平，电机也没有 z 向力偶。
仅从直立开始；Δx ≠ 0，允许横滚上轮电机首先激起横滚 φ；惯量积 Ixz 使偏航立即出现瞬态。不必先有俯仰。
仅从直立开始；Δy ≠ 0，俯仰保持为零上轮电机可激起横滚，但 Δy 新增的是俯仰—偏航耦合；这一项不产生偏航。
要求最后恢复直立并留下目标朝向固定接地点理想模型中，单一横滚或俯仰往返的偏航会抵消；需利用另一耦合过程或轮地接触效应。

必须补上一项：即使 Δx = Δy = 0，只要下轮正在转，上轮电机让机身横滚，下轮轮轴就会被带着倾斜，下轮角动量出现竖直分量，也能耦合出偏航。上表讨论的是偏置额外增加的项，不能据此判断整台机器人是否能转。见不偏置时的逐帧图解。

上式是把前后偏置与侧向偏置放在同一个小扰动方程中的教学表达；它省略了下轮旋转与横滚的固有耦合。“立即出现”指初始偏航加速度可非零，并不表示电机产生了直接 z 向力矩。真实机器人还存在轮地约束和摩擦，上式不能单独证明持续转向能力。

一句话结论

沿 y 偏置上飞轮，首先让车想侧倾；同时通过 Iyz 把俯仰与偏航连起来。固定侧偏置确实会影响转向动力学，但它本身不是一个独立的转向执行器。

资料：Mini Wheelbot 论文说明原机使用非线性陀螺效应实现受控偏航；开源仿真模型可作为加入侧偏置的基线。本文 Δy 推导是基于假设改装的独立分析。
