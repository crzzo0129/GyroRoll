# 双飞轮固定速比验证

两个转轴都按机身 +x 方向定义，速度均为相对机身的关节角速度。两轮零初始角、零初速。

- `equal.xml`：位置约束 `q左 = q右`，对应 `ω左 = ω右`；电机力矩分配 `[τ/2, τ/2]`。
- `opposite.xml`：位置约束 `q左 = -q右`，对应 `ω左 = -ω右`；电机力矩分配 `[τ/2, -τ/2]`。

每次回放固定一种模式，不在运动中改变速比。不直接覆写关节位置或速度；约束由 MuJoCo 求解。如果以后需要模式切换，连续切换必须经过两轮都为零的交点。

重要：MuJoCo 的 joint equality 是有数值柔性的约束，不保证逐位相等。同向模式此次最大速度残差约 `3.7e-12 rad/s`；反向模式最大残差约 `0.0245 rad/s`，不能把反向模型宣称为已达到严格零残差。两种约束模型均不是实物传动或电子同步精度的保证。

检查范围：两种模式 × ±1° 初始 roll × 2/1/0.5 ms 步长 × 静止/从零起步，共 24 次回放。同向模式 12/12 完成 15 秒；反向模式 0/12 完成。反向模式使用相同控制器尝试纠偏，只用于检验同向平衡控制不能直接迁移，不是反向模式控制器优化结果。相同飞轮严格等速反向时，相对机身的自旋角动量及其变化相互抵消，不能用这一路直接生成 roll 反作用控制力矩。

`summary.json` 保存每次回放与每个物理子步统计出的速度约束残差；CSV 保存代表回放。此前 `../structure_comparison/report.html` 是独立电机、近似同向的历史对照，不应当作固定速比试验。

复现：在项目根目录运行 `.venv-mjlab/Scripts/python.exe probe_flywheel_coupling.py`。
