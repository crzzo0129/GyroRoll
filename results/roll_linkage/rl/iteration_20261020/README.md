# Roll-linkage 自主迭代记录（2026-10-20）

本轮保持 `model_level_torso.xml` 的自由躯干、物理四连杆和两个 2.4 Nm
执行器不变。改动涉及训练、初始化、数值精度和评估流程。

## 已确认结果

所有下表测试均为确定性神经网络策略；每项包含 16 个初始 Roll/Pitch
扰动样本。通过还要求速度、转向、侧向速度、躯干姿态和闭环误差达标。

| 策略/测试 | 初始倾角 | 时长 | 存活/通过 |
|---|---:|---:|---:|
| 原 V1 `model_2800.pt`，站立 | ±0.1° | 12 s | 0/16 |
| V2 纯 PPO，前两轮站立评估 | ±0.1° | 12 s | 0/16 |
| V3 初始化网络，默认 TF32，站立 | ±0.1° | 12 s | 0/16 |

破坏这些已测能力，不能证明长期收敛或转向能力。

## 发现与修复

1. 旧策略主要把连杆推到摆角边界后摔倒，并非力矩上限不足。
2. 同步 CPU/GPU 物理对照没有发现足以解释失败的后端差异。
3. 默认 TF32 会破坏高增益反馈；训练和回放均使用完整 FP32。
4. V3 的 ELU 大偏置相消对更新敏感，1e-5 的短程更新会破坏平衡。
   V4 用 ReLU 正负通道表示相同初始反馈，消除大偏置相消。
5. 从站立直接进入 ±0.3 m/s 难度过高。课程先测试 ±0.03、±0.075、
   ±0.15，再到 ±0.3 m/s，最后完整混合任务。
6. 每个训练区间都进行独立评估；退化则恢复保留模型和优化器状态，
   学习率减半。接受新模型前复查全部已通过课程。

默认 reset 将轮胎放到静态接触位置；它不代表“离地释放”鲁棒性。
另测 V3 离地释放仅 14/16 通过，未达到升级标准，尚未解决。
